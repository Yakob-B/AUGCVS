## 🎨 Image Optimization Tips:

1. **Compress Images**: Use TinyPNG, ImageOptim, or Squoosh
2. **WebP Format**: Consider WebP for better compression (browser support required)
3. **File Sizes**: 
   - Logo: Under 200KB
   - Favicon: Under 50KB
   - Campus images: Under 2MB each
4. **Aspect Ratios**: Maintain 16:9 for campus images for best display
5. **Transparent Backgrounds**: Use PNG for logos when possible
