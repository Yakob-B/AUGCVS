### Key Features
- **Role-Based Access** – Admin • Registrar • External Companies (300+ verifications handled)
- **Secure PDF + QR Verification** – 100% validation accuracy with Multer uploads
- **Real-Time Notifications** – Socket.IO powered for instant updates
- **Audit Logging & Activity Tracking** – Full compliance and security
- **Black-Themed Responsive UI** – Figma-designed, 40% faster onboarding
- **Email Integration** – Nodemailer for automated alerts

### Tech Stack
`React 18` `Vite` `Tailwind CSS` `Node.js` `Express` `MongoDB` `Socket.IO`  
`JWT + bcrypt` `Multer` `Nodemailer` `Vercel` `MongoDB Atlas`
