### Key Features
- **Role-based Access** – Admin • Registrar • External Companies  
- **Secure PDF + QR Verification** – 100% validation accuracy  
- **Real-time Notifications** – Socket.IO powered  
- **Audit Logging & Activity Tracking**  
- **Black-themed Responsive UI** – Built from Figma, 40% faster onboarding  
- **File Upload + Email Notifications** (Nodemailer)

### Tech Stack
`React 18` `Vite` `Tailwind CSS` `Node.js` `Express` `MongoDB` `Socket.IO`  
`JWT + bcrypt` `Multer` `Nodemailer` `Vercel`
