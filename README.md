## Key Features
- **Role-Based Access**: Admin • Registrar • External Users (handles 300+ verifications)
- **Secure PDF/QR Upload**: 100% validation accuracy with Multer + Express Validator
- **Real-Time Updates**: Socket.IO for instant notifications
- **Audit Logs & Emails**: Full tracking + Nodemailer integration
- **Responsive Black UI**: Figma-based, 40% faster onboarding (Tailwind CSS)
- **Performance**: MongoDB indexes, pagination, optimized queries

## Tech Stack
`React 18` `Vite` `Tailwind` `Node.js` `Express` `MongoDB` `Socket.IO` `JWT` `bcrypt` `Multer` `Nodemailer` `Vercel`
