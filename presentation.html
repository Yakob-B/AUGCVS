Capstone Project 2025

AUGCVS

Ambo University Graduation Credential
Verification System

Full-stack MERN platform digitizing secure graduate credential verification

🎯 Problem Statement

📝

Current Challenges

  • Manual, paper-based verification process
  • Time-consuming credential validation
  • Risk of forged certificates going undetected
  • No centralized graduate database
  • Difficult to track verification history
💡

Our Solution

  • Digital platform for instant verification
  • Secure graduate records database
  • Real-time verification status updates
  • Complete audit trail and logging
  • Role-based access control system

✨ Key Features

🔐

Role-Based Access

Superadmin, Admin, Registrar, and External user roles with granular permissions

📄

Secure File Upload

PDF/QR certificate upload with 100% validation accuracy using Multer

⚡

Real-Time Updates

Socket.IO integration for instant verification status notifications

📊

Audit Logging

Complete tracking of all verification activities and system actions

📧

Email Notifications

Automated email alerts via Nodemailer for verification updates

🤖

AI Assistant

Intelligent chatbot to help users navigate the system

🏗️ System Architecture

🎨

Client Layer

  • React SPA with Vite build system
  • Context API for state management
  • Protected routes with role guards
  • Responsive dark theme UI
⚙️

API Layer

  • RESTful endpoints with Express
  • JWT authentication middleware
  • Rate limiting & CORS protection
  • File upload handling with Multer
💾

Data Layer

  • MongoDB with indexes for performance
  • Mongoose schemas with validation
  • Text search for graduate lookup
  • Pagination for large datasets
🔒

Security Layer

  • Password hashing with bcrypt
  • JWT token authentication
  • Email verification flow
  • Password reset functionality

📊 Database Models

👤

User Model

  • firstName, lastName, email
  • Password (hashed)
  • Role (superadmin/admin/registrar/external)
  • Organization, Status
  • Email verification tokens
🎓

Graduate Model

  • Student ID, Full Name
  • Department, College, Program
  • Degree Type, GPA
  • Graduation Date/Year
  • Certificate Number
✅

Verification Model

  • Request Number
  • Requester & Graduate refs
  • Certificate File
  • Status (pending/approved/rejected)
  • Verification Result

🔄 Verification Process Flow

  1. 1

    Request Submission

    External user submits verification request with certificate file and details

  2. 2

    Graduate Matching

    System matches certificate number with graduate database records

  3. 3

    Registrar Review

    Registrar reviews request, verifies documents, and makes decision

  4. 4

    Result Notification

    Requester receives instant notification with verification result
